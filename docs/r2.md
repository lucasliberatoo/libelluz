# Arquivos no Cloudflare R2

Os materiais (PDF, vídeo, áudio…) vão direto do navegador para o R2 por uma URL pré-assinada. O servidor da Vercel nunca recebe o arquivo, só assina a URL. Limites: 500 MB por arquivo e 2 GB por pessoa. Sem as variáveis abaixo, o app esconde o upload e aceita só links.

## 1. Criar o bucket

1. No painel da Cloudflare, abra **R2 Object Storage** e clique em **Create bucket**.
2. Nome: `libelluz` (ou outro; ele vai na variável `R2_BUCKET`). Localização: automática. Deixe o bucket **privado** (sem domínio público).

## 2. Criar a chave de API

1. Na página do R2, clique em **Manage R2 API Tokens** e depois em **Create API Token**.
2. Permissão: **Object Read & Write**.
3. Em *Specify bucket(s)*, escolha **Apply to specific buckets only** e marque o bucket `libelluz`.
4. Crie o token e copie o **Access Key ID** e o **Secret Access Key**. A secret só aparece uma vez.
5. O **Account ID** fica na lateral direita da página do R2 e também na URL do painel (`dash.cloudflare.com/<account-id>/r2`).

## 3. CORS do bucket

Abra o bucket, vá em **Settings → CORS Policy → Add CORS policy** e cole:

```json
[
  {
    "AllowedOrigins": ["https://libelluz.vercel.app", "http://localhost:3000"],
    "AllowedMethods": ["GET", "PUT", "HEAD"],
    "AllowedHeaders": ["content-type"],
    "ExposeHeaders": ["ETag"],
    "MaxAgeSeconds": 3600
  }
]
```

Se você testar pelos links de preview da Vercel (`https://libelluz-git-…vercel.app`), adicione cada endereço em `AllowedOrigins`, porque o R2 não aceita curinga no meio do domínio. O apagar (DELETE) é feito pelo servidor, então não precisa entrar no CORS.

## 4. Variáveis na Vercel

Em **Vercel → projeto libelluz → Settings → Environment Variables**, crie as quatro abaixo (Production e Preview) e faça um novo deploy:

| Variável | Valor |
|---|---|
| `R2_ACCOUNT_ID` | Account ID da Cloudflare |
| `R2_ACCESS_KEY_ID` | Access Key ID do token |
| `R2_SECRET_ACCESS_KEY` | Secret Access Key do token |
| `R2_BUCKET` | `libelluz` |

Para testar no seu computador, coloque as mesmas linhas no `.env.local`.

## Como conferir

Entre como admin em **Aulas → Materiais**. Enquanto faltar alguma variável, aparece "Upload de arquivos ainda não configurado — use links" e uma linha com as variáveis que faltam (só o admin vê essa linha). Com tudo certo, aparece a barra "Seu espaço de arquivos" e a opção **Arquivo** no botão **Adicionar**. Se o envio falhar com "Falha de rede", o problema costuma ser o CORS do passo 3.
